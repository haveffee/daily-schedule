# Персональное расписание

GitHub Actions запускает `generate.py` каждый день в 04:20 UTC (07:20 в Москве) и обновляет `index.html`. Статический сайт размещён через GitHub Pages, поэтому он доступен, даже когда компьютер выключен.

## Месячные цели и план

До трёх целей на месяц и их пошаговый план отображаются в расписании дня и сохраняются в браузере. При входе через Google цели, шаги и отметки выполнения хранятся отдельно для каждого пользователя в Firestore по пути `users/{uid}/planning/{YYYY-MM}` и обновляются между устройствами.

Правила Firestore в `firestore.rules` разрешают доступ к планам только владельцу соответствующего `uid`. После изменения правил их нужно опубликовать в Firebase Console: **Firestore Database → Rules → Publish**. Доступ к данным других аккаунтов не открывается.

## Локальный планировщик Qwen

План создаёт Qwen3 через Transformers.js непосредственно в браузере. Цели, расписание и задачи не отправляются AI-провайдеру, и API-ключ не нужен. На совместимом компьютере с WebGPU и не менее 8 ГБ памяти выбирается Qwen3-1.7B (около 1,43 ГБ весов); на телефоне или другом устройстве — Qwen3-0.6B (около 570 МБ через WebGPU, около 919 МБ через CPU). Загрузка нужна при первом использовании; далее браузер может использовать кэш.

Локальная небольшая модель может иногда дать общий или неполный план. Приложение проверяет её ответ и подставляет практичные резервные шаги, если ответ не соответствует формату. Для обучающих задач сайт формирует поиск YouTube по теме и упражнению; он не сканирует интернет и не выбирает конкретное видео автоматически.

Скрипт генерирует ежедневную страницу для часового пояса `Europe/Moscow`, а пользовательские цели и отметки не перезаписываются ежедневным GitHub Actions запуском.
